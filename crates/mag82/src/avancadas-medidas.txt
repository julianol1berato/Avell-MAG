# Cada linha: tipo, vaga, código da função (hex) e a resposta. "recusado" é a resposta com 0xFF no
# lugar do tipo; "aceito" é o pacote repetido e a leitura seguinte devolvendo o que foi gravado.
# Nos pares (socd, rs) o código é a função de uma das duas teclas do par.
#
# "aceito" não quer dizer que funciona: uma tecla com modificadores (códigos de 0100 a 0fff, como
# 0107 = Ctrl + D) é aceita e lida de volta, mas ao digitar o teclado envia só a tecla, sem o
# modificador. Conferido digitando em 2026-11-27: tecla remapeada, multiponto, contínuo e DKS com
# 0107 enviaram só "d"; multiponto com 0304 (Ctrl + Shift + A) enviou só "a".
#
# As combinações de verdade levam a marca 0x10 no byte alto (1807 = Super + D, como vem de fábrica
# em Fn + F4); essas o teclado recusa em toda função avançada. As funções de mouse (4100 a 4b01) ele
# aceita gravar no DKS e recusa nos outros tipos; não foi conferido se funcionam no DKS, e o
# programa não as oferece.
